# Report regeneration

Run `python -m scripts.build_academic_report` from the project root after importing data, executing SQL, rebuilding supporting outputs and running tests. The report builder includes source listings and actual result samples. It generates Report/Academic_Report.docx and editable Markdown source.

Use LibreOffice or Word to export the DOCX to PDF and inspect every rendered page. The supplied PDF was created by the bundled document renderer and corresponds to the delivered DOCX. Do not reuse its validation note after changing data or report content. Browser screenshots are absent because access was denied; they require authorized manual or browser capture. No certificate or signed declaration is fabricated.
