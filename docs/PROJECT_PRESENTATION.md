# Project presentation

1. Problem: scattered job observations make skill and salary research difficult.
2. Objectives: reproducible cleaning, relational storage, evidence-backed exploration and exports.
3. Source: genuine Kaggle CSV, historical observations, checksum and field audit.
4. Architecture: Python pipeline, four SQLite tables, SQL and Python analytics, Streamlit.
5. Methodology: composite deduplication, salary fallback, unknown preservation and skill parsing.
6. Demonstration: global filters, executive KPIs, salary, skills and employers.
7. SQL evidence: median, optimal skills, co-occurrence and observation trends.
8. Quality: missing salaries, duplicate counts and invalid candidates.
9. Testing: show actual pytest and SQL validation records.
10. Deliverables: working app, database, Excel, report and Power BI support assets.
11. Limitations: no verified global job countries, source currency or explicit onsite controls; historical coverage.
12. Future work: verified metadata, native PBIX, production database adapter and controlled predictive evaluation.

Use real Report/charts and Screenshots assets for slides. Do not replace execution evidence with illustrative dashboard art.
