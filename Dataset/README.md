# Data provenance

The original user-local CSV is preserved under raw by its SHA-256 prefix. current.json points to the committed version under processed. Read quality.json for exact checksum, source URL, processing time, missingness and method limitations.

This is a historical snapshot, not a live feed. The original download time is unknown. The source license was not verified; do not publish the raw or processed data until redistribution terms are confirmed. All observations target United States searches; this is not verified global workplace-country data. Monetary units are unverified source currency.
